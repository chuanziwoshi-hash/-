# 码伴 CodeMate 使用说明

码伴 CodeMate 是一个浏览器扩展，用来在刷算法题时提供一个悬浮代码编辑器。它可以同步题目上下文，给出下一步代码建议，检查已有代码，解释选中代码，并把代码写入网页编辑器。

## 1. 安装扩展

1. 打开 Chrome、Edge 或其他 Chromium 内核浏览器。
2. 进入扩展管理页：
   - Chrome：`chrome://extensions/`
   - Edge：`edge://extensions/`
3. 打开“开发者模式”。
4. 点击“加载已解压的扩展程序”。
5. 选择本项目根目录，也就是包含 `manifest.json` 的文件夹。
6. 浏览器右上角会出现扩展图标，点击后可以打开配置弹窗。

修改代码后，一般需要回到扩展管理页点击“重新加载”，再刷新正在使用的题目页面。

## 2. 基础配置

点击扩展图标打开配置弹窗。

### AI 接口

- `AI API 地址`：填写兼容 OpenAI Chat Completions 的接口地址，例如 `https://api.openai.com/v1/chat/completions`。
- `模型`：填写要使用的模型名。
- `超时时间`：AI 请求等待时间，默认 90 秒。
- `最大输出长度`：单次请求的输出上限，默认 8192 token。检查通常先分配 4096 token，复杂请求可使用更高预算；达到上限时最多增加预算重试一次，且不超过此设置。推理内容可能占用其中一部分，请按接口实际能力设置。
- `模型上下文容量`：输入和输出的总容量，默认按 32768 token 估算，用于自动分段。它不会改变模型本身的容量，需按所用接口填写。长度估算并非模型专用分词器，接口报告上下文不足时会尝试缩小当前段。
- `输出长度参数`：推荐自动适配；也可按兼容服务要求指定 `max_tokens` 或 `max_completion_tokens`。
- `推理设置`：默认不额外指定。只有确认接口支持时才选择较低推理强度、关闭推理或 `enable_thinking` 关闭思考。
- `API Key`：如果接口需要鉴权就填写；本地服务或无鉴权服务可以留空。

配置完成后，点击“保存配置”。可以点击“测试 AI 连接”确认接口是否可用。

### 题目来源

题目来源决定“同步题目”按钮从哪里读取题面。

- `自动`：优先识别洛谷、力扣题目页，失败后读取当前网页正文。
- `只连接洛谷题目页`：只处理洛谷题目页面。
- `只连接力扣题目页`：只处理力扣题目页面。
- `只读取当前网页内容`：不识别平台结构，直接取页面正文。
- `自定义题目服务器`：向你填写的服务器地址发送当前页面信息，由服务器返回题目文本。

自定义服务器可以分别控制是否发送题面正文、网页选中文本和当前代码。默认只发送题面正文，不发送选中文本和代码。服务器 Token 使用 Bearer 鉴权，并保存在扩展本地存储中。

“测试题目来源”会优先访问服务器的 `/health` 接口；旧服务器没有该接口时，会自动回退到测试题目请求。完整协议和环境变量参见 `server-example/README.md`。

## 3. 打开悬浮助手

进入题目页面后，右下角会出现 `码` 悬浮按钮。

- 点击 `码`：打开或收起助手面板。
- 拖动 `码` 按钮：可以改变按钮位置。
- 面板标题栏可拖动。
- 面板右下角可拉伸。
- 面板左上角也有拉伸手柄，可以从左上方向调整大小。

全局显隐快捷键：

```text
Ctrl/Cmd + B
```

## 4. 常用工作流

推荐使用顺序：

1. 打开题目页面。
2. 点击右下角 `码` 打开助手。
3. 点击“同步题目”，让助手读取题目上下文。
4. 在代码框里写代码。
5. 光标停在你写到的位置。
6. 点击“下一段该写什么”获取下一步建议。
7. 需要时点击“采用建议”，先预览位置，再点击“确认插入”。
8. 写完或卡住时点击“检查已有代码”。

## 5. 主要按钮说明

### 同步题目

读取当前网页或题目服务器的题面内容。同步成功后，AI 会结合题目上下文理解你的代码。

### 下一段该写什么

根据题目、当前代码和光标位置，判断下一步应该补哪一小段代码。

建议会尽量围绕当前光标附近，不直接重写整份代码。

### 停止生成

当“下一段该写什么”“检查已有代码”或“解释选中代码”正在等待 AI 返回时，按钮区会临时显示“停止生成”。

点击后会取消当前 AI 请求，并恢复按钮状态。它只影响当前正在运行的一次 AI 请求，不会清空代码框或题面内容。

### 检查已有代码

检查当前代码里的问题，包括：

- 语法错误
- 变量名错误
- 输入输出不匹配
- 边界情况
- 复杂度风险
- 可能和题意不一致的地方

AI 回答里如果出现“第 N 行”，行号会变成可点击链接。点击后会跳到代码框对应行并高亮。

短代码一次检查，长代码按字符预算、行数和代码边界自动分段，保留原始行号，代码尾部不会被裁掉。超长单行也会分段。各段完成后会复核整体算法和跨段逻辑，需要时补查关联代码；全局摘要较多时也会分批合并。

检查期间显示已完成段数、当前范围和已发现问题，已完成的结论会立即显示。点击“停止生成”会停止当前请求和后续任务，保留已完成结果。检查未全部完成时显示“重试未完成部分”，只补查失败或尚未执行的部分。

输出截断不会被当作完整答案；增加预算后仍截断时，只缩小当前段，最多再细分两层。网络、超时和临时服务错误最多自动重试一次，认证或配置错误会直接停止。每次请求的超时覆盖连接、等待和完整响应读取。达到重试上限仍失败时显示最后一次真实错误，并注明尚未完成的范围。

检查使用点击时的代码快照。期间编辑代码、题面或语言，结果会标注为旧版本，并关闭旧行号跳转和继续补查；请点击“检查已有代码”检查新版本。窗口保留期间可补查；刷新网页会清除本次检查进度。

分段与全局复核可能增加请求次数和 API 用量。出现“仍需进一步核实”时，本次检查仍未完成，不能据此认定代码没有问题。

### 解释选中代码

先在代码框中选中一段代码，再点击“解释选中代码”。

AI 会解释：

- 这段代码整体作用
- 关键语句执行顺序
- 重要变量变化
- 边界和风险
- 它和题目算法的关系

没有选中代码时不会发送 AI 请求。

### 采用建议

差异确认窗口完整显示修改前后的代码，不省略未改动部分。代码较长时可以上下滚动查看，较长的单行可以左右滚动；也可以拖动窗口边角调整大小。

“采用建议”是两步操作：

1. 第一次点击：只预览插入位置，不修改代码。
2. 第二次点击：按钮变成“确认插入”，再次点击才真正插入。

如果你在预览期间点击代码框、继续编辑、格式化代码或重新请求 AI，预览会自动取消，避免误插旧位置。

### 写入网页编辑器

把助手代码框里的代码插入到当前网页的代码编辑器中。

对力扣页面，扩展会优先尝试直接写入编辑器。如果直接写入失败，会尝试复制到剪贴板并通过调试器粘贴。

### 撤销改动

撤销最近一次由助手执行的代码改动。

支持撤销：

- 采用建议
- 插入到普通网页输入框
- 插入到部分页面编辑器
- 插入到力扣编辑器的快照恢复

## 6. 代码框功能

代码框针对算法题写代码做了一些轻量增强：

- 行号显示
- 当前行高亮
- 点击 AI 回答里的“第 N 行”可定位到代码框行号
- Tab 缩进和 Shift+Tab 反缩进
- Enter 自动缩进
- 括号、引号自动成对补全
- Backspace 删除空括号对
- 格式化代码
- 自动保存草稿

草稿按当前网站来源和路径保存。刷新页面后，助手会尝试恢复之前写过的代码和题面。

### 最近草稿

代码工具栏里有“最近草稿”下拉菜单，会保留最近 5 次代码快照。

它适合处理这些情况：

- 误删了一段代码。
- 格式化后想回到格式化前。
- 采用建议后想找回插入前的版本。
- 刷新页面后想回到较早的草稿。

选择某个草稿后会恢复代码、选区和滚动位置。恢复前，当前代码也会先保存一份历史，方便再切回来。

## 7. 快捷键

面板内快捷键只在助手面板打开，并且焦点位于助手内部时生效，避免抢占题目网页自身快捷键。

| 快捷键 | 功能 |
| --- | --- |
| `Ctrl/Cmd + B` | 显示或隐藏助手 |
| `Ctrl/Cmd + Enter` | 下一段该写什么 |
| `Ctrl/Cmd + Shift + Enter` | 检查已有代码 |
| `Ctrl/Cmd + E` | 解释选中代码 |
| `Shift + Alt + F` | 格式化代码 |

`Shift + Alt + F` 用于避免和 QQ 登录后的 `Ctrl+Alt` 系列快捷键冲突。

## 8. 建议范围

“建议范围”用于控制 AI 给代码建议时的改动边界。

- `只补光标处一小段`：最保守，适合日常写题。
- `只补当前代码块`：限制在当前 `if/for/while/switch` 或邻近代码块内。
- `只补当前函数`：限制在当前函数或方法内部。

一般推荐默认使用“只补光标处一小段”，可以减少 AI 一次性改太多导致混乱。

## 9. 格式化代码

点击“格式化”或使用：

```text
Shift + Alt + F
```

格式化逻辑是内置的轻量整理，适合快速处理缩进和空行，不等同于完整语言格式化器。

当前会根据代码和语言选择做基础格式化，例如：

- C/C++/Java/JavaScript/Go/C# 等括号语言的缩进
- Python 的基础缩进整理
- 清理多余空行和行尾空白

## 10. 常见问题

### AI 没有读到题目

先确认：

- 当前页面是否是题目页。
- 是否点击了“同步题目”。
- 弹窗里的题目来源是否配置正确。
- 如果使用自定义题目服务器，服务器是否启动，地址是否正确。

可以在弹窗里点击“测试题目来源”。

### 插入到力扣失败

可能原因：

- 页面编辑器还没加载完成。
- 浏览器没有允许调试器权限。
- 页面焦点不在代码编辑器。

可以先点击力扣代码编辑器，再回到助手点击“写入网页编辑器”。如果自动写入失败，助手通常会把代码复制到剪贴板，可以手动 `Ctrl+V`。

### AI 回答覆盖了代码框

这是布局问题已处理过。如果再次出现，刷新扩展和页面后重试，并确认使用的是最新代码。

### 快捷键没有反应

快捷键需要满足：

- 助手面板处于打开状态。
- 焦点在助手内，例如代码框、题面框或输出区。
- 没有被其他软件抢占。

如果某个快捷键和本机软件冲突，可以换成按钮操作。

## 11. 开发者检查命令

修改 JavaScript 后，可以在项目根目录运行：

```powershell
node --check background\background.js
node --check background\ai-client.js
node --check content\assistant-core.js
node --check content\ai-budget.js
node --check content\code-review.js
node --check content\content-script.js
node --check frontend\popup\popup.js
node --check server-example\problem-server.js
```

这些命令只检查语法，不会启动扩展。

运行回归测试：

```powershell
node --test tests/*.test.js
```

AI 接口测试使用模拟响应，不会调用真实付费模型；实际接口请在配置弹窗中测试。
