# 码伴 CodeMate 使用说明

码伴 CodeMate 是一个浏览器扩展，用来在刷算法题时提供一个悬浮代码编辑器。它可以同步题目上下文，给出下一步代码建议，检查已有代码，解释选中代码，并把代码插入到页面编辑器中。

## 1. 安装扩展

1. 打开 Chrome、Edge 或其他 Chromium 内核浏览器。
2. 进入扩展管理页：
   - Chrome：`chrome://extensions/`
   - Edge：`edge://extensions/`
3. 打开“开发者模式”。
4. 点击“加载已解压的扩展程序”。
5. 选择本项目根目录，也就是包含 `manifest.json` 的文件夹。
6. 浏览器右上角会出现扩展图标，点击后可以打开配置弹窗。

修改代码后，一般需要回到扩展管理页点击“重新加载”，再刷新正在使用的题目页面。

## 2. 基础配置

点击扩展图标打开配置弹窗。

### AI 接口

- `AI API 地址`：填写兼容 OpenAI Chat Completions 的接口地址，例如 `https://api.openai.com/v1/chat/completions`。
- `模型`：填写要使用的模型名。
- `超时时间`：AI 请求等待时间，默认 90 秒。
- `API Key`：如果接口需要鉴权就填写；本地服务或无鉴权服务可以留空。

配置完成后，点击“保存配置”。可以点击“测试 AI 连接”确认接口是否可用。

### 题目来源

题目来源决定“同步题目”按钮从哪里读取题面。

- `自动`：优先识别洛谷、力扣题目页，失败后读取当前网页正文。
- `只连接洛谷题目页`：只处理洛谷题目页面。
- `只连接力扣题目页`：只处理力扣题目页面。
- `只读取当前网页内容`：不识别平台结构，直接取页面正文。
- `自定义题目服务器`：向你填写的服务器地址发送当前页面信息，由服务器返回题目文本。

如果要使用自定义题目服务器，可以参考 `server-example/problem-server.js` 和 `server-example/README.md`。

## 3. 打开悬浮助手

进入题目页面后，右下角会出现 `码` 悬浮按钮。

- 点击 `码`：打开或收起助手面板。
- 拖动 `码` 按钮：可以改变按钮位置。
- 面板标题栏可拖动。
- 面板右下角可拉伸。
- 面板左上角也有拉伸手柄，可以从左上方向调整大小。

全局显隐快捷键：

```text
Ctrl/Cmd + B
```

直接打开独立编辑窗口：

```text
Ctrl + M
```

## 4. 常用工作流

推荐使用顺序：

1. 打开题目页面。
2. 点击右下角 `码` 打开助手。
3. 点击“同步题目”，让助手读取题目上下文。
4. 在代码框里写代码。
5. 光标停在你写到的位置。
6. 点击“下一段该写什么”获取下一步建议。
7. 需要时点击“插入建议”，先预览位置，再点击“确认插入”。
8. 写完或卡住时点击“检查已有代码”。

## 5. 主要按钮说明

### 同步题目

读取当前网页或题目服务器的题面内容。同步成功后，AI 会结合题目上下文理解你的代码。

### 下一段该写什么

根据题目、当前代码和光标位置，判断下一步应该补哪一小段代码。

建议会尽量围绕当前光标附近，不直接重写整份代码。

### 停止生成

当“下一段该写什么”“检查已有代码”或“解释选中代码”正在等待 AI 返回时，按钮区会临时显示“停止生成”。

点击后会取消当前 AI 请求，并恢复按钮状态。它只影响当前正在运行的一次 AI 请求，不会清空代码框或题面内容。

### 检查已有代码

检查当前代码里的问题，包括：

- 语法错误
- 变量名错误
- 输入输出不匹配
- 边界情况
- 复杂度风险
- 可能和题意不一致的地方

AI 回答里如果出现“第 N 行”，行号会变成可点击链接。点击后会跳到代码框对应行并高亮。

### 解释选中代码

先在代码框中选中一段代码，再点击“解释选中代码”。

AI 会解释：

- 这段代码整体作用
- 关键语句执行顺序
- 重要变量变化
- 边界和风险
- 它和题目算法的关系

没有选中代码时不会发送 AI 请求。

### 插入建议

“插入建议”是两步操作：

1. 第一次点击：只预览插入位置，不修改代码。
2. 第二次点击：按钮变成“确认插入”，再次点击才真正插入。

如果你在预览期间点击代码框、继续编辑、格式化代码或重新请求 AI，预览会自动取消，避免误插旧位置。

### 插入到页面

把助手代码框里的代码插入到当前网页的代码编辑器中。

对力扣页面，扩展会优先尝试直接写入编辑器。如果直接写入失败，会尝试复制到剪贴板并通过调试器粘贴。

### 撤销插入

撤销最近一次由助手执行的插入操作。

支持撤销：

- 插入建议
- 插入到普通网页输入框
- 插入到部分页面编辑器
- 插入到力扣编辑器的快照恢复

## 6. 代码框功能

代码框针对算法题写代码做了一些轻量增强：

- 行号显示
- 当前行高亮
- 点击 AI 回答里的“第 N 行”可定位到代码框行号
- Tab 缩进和 Shift+Tab 反缩进
- Enter 自动缩进
- 括号、引号自动成对补全
- Backspace 删除空括号对
- 格式化代码
- 自动保存草稿

草稿按当前网站来源和路径保存。刷新页面后，助手会尝试恢复之前写过的代码和题面。

### 最近草稿

代码工具栏里有“最近草稿”下拉菜单，会保留最近 5 次代码快照。

它适合处理这些情况：

- 误删了一段代码。
- 格式化后想回到格式化前。
- 插入建议后想找回插入前的版本。
- 刷新页面后想回到较早的草稿。

选择某个草稿后会恢复代码、选区和滚动位置。恢复前，当前代码也会先保存一份历史，方便再切回来。

## 7. 快捷键

浏览器级快捷键：

| 快捷键 | 功能 |
| --- | --- |
| `Ctrl + M` | 直接打开独立编辑窗口（Windows/Linux 默认） |

面板内快捷键只在助手面板打开，并且焦点位于助手内部时生效，避免抢占题目网页自身快捷键。

| 快捷键 | 功能 |
| --- | --- |
| `Ctrl/Cmd + B` | 显示或隐藏助手 |
| `Ctrl/Cmd + Enter` | 下一段该写什么 |
| `Ctrl/Cmd + Shift + Enter` | 检查已有代码 |
| `Ctrl/Cmd + E` | 解释选中代码 |
| `Shift + Alt + F` | 格式化代码 |

`Shift + Alt + F` 用于避免和 QQ 登录后的 `Ctrl+Alt` 系列快捷键冲突。

浏览器级快捷键可以在 `chrome://extensions/shortcuts` 或 `edge://extensions/shortcuts` 中修改。

## 8. 建议范围

“建议范围”用于控制 AI 给代码建议时的改动边界。

- `只补光标处一小段`：最保守，适合日常写题。
- `只补当前代码块`：限制在当前 `if/for/while/switch` 或邻近代码块内。
- `只补当前函数`：限制在当前函数或方法内部。

一般推荐默认使用“只补光标处一小段”，可以减少 AI 一次性改太多导致混乱。

## 9. 格式化代码

点击“格式化”或使用：

```text
Shift + Alt + F
```

格式化逻辑是内置的轻量整理，适合快速处理缩进和空行，不等同于完整语言格式化器。

当前会根据代码和语言选择做基础格式化，例如：

- C/C++/Java/JavaScript/Go/C# 等括号语言的缩进
- Python 的基础缩进整理
- 清理多余空行和行尾空白

## 10. 常见问题

### AI 没有读到题目

先确认：

- 当前页面是否是题目页。
- 是否点击了“同步题目”。
- 弹窗里的题目来源是否配置正确。
- 如果使用自定义题目服务器，服务器是否启动，地址是否正确。

可以在弹窗里点击“测试题目来源”。

### 插入到力扣失败

可能原因：

- 页面编辑器还没加载完成。
- 浏览器没有允许调试器权限。
- 页面焦点不在代码编辑器。

可以先点击力扣代码编辑器，再回到助手点击“插入到页面”。如果自动插入失败，助手通常会把代码复制到剪贴板，可以手动 `Ctrl+V`。

### AI 回答覆盖了代码框

这是布局问题已处理过。如果再次出现，刷新扩展和页面后重试，并确认使用的是最新代码。

### 快捷键没有反应

快捷键需要满足：

- 如果是 `Ctrl + M`，需要先在浏览器的扩展快捷键页面确认没有冲突或被禁用。
- 助手面板处于打开状态。
- 焦点在助手内，例如代码框、题面框或输出区。
- 没有被其他软件抢占。

如果某个快捷键和本机软件冲突，可以换成按钮操作。

## 11. 开发者检查命令

修改 JavaScript 后，可以在项目根目录运行：

```powershell
node --check background\background.js
node --check content\assistant-core.js
node --check content\content-script.js
node --check frontend\popup\popup.js
node --check server-example\problem-server.js
```

这些命令只检查语法，不会启动扩展。
